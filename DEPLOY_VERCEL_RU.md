# FindBest.de на Vercel

Render больше не используется. Сайт живёт как проект Vercel, подключённый к репозиторию `findbest1` (ветка `main`) — каждый push в `main` автоматически передеплоивает.

## Что работает сейчас

- Поиск (`/api/search`) — Google Shopping через Serper + eBay Browse API, полностью рабочий.
- Все статические страницы: `index.html`, `results.html`, `favorites.html`, `reviews.html`, `admin-reviews.html`.
- `/api/config`, `/api/status`, `/api/health`.

## Что временно отключено

Отзывы, модерация и ценовые алерты отдают `503` ("недоступно") — это тот же самый режим деградации, что и в обычном Node-сервере, когда не настроено постоянное хранилище: страницы не ломаются, просто показывают "сервис недоступен".

Причина: им нужна база данных с постоянным подключением (SQLite не работает на Vercel — нет диска) и Telegram-бот в режиме webhook (не long-polling). Это будет отдельным шагом, когда появится база (Turso).

## Переменные окружения (Vercel → Settings → Environment Variables)

Обязательно:
- `SERPER_API_KEY` — ключ Serper для живого поиска.

Опционально:
- `SEARCH_LOCATION` (по умолчанию `Germany`)
- `CACHE_TTL_SECONDS` (по умолчанию `180`)
- `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET` — для поиска через eBay Browse API.

После добавления/изменения переменных — **Redeploy** (Vercel не подхватывает их на лету для уже собранного деплоя).

## Как проверить после деплоя

1. Открыть `/api/health` — должно быть `{"status":"ok",...}`.
2. Открыть `/api/status` — проверить, что `googleShopping: true` (если задан ключ).
3. Открыть главную страницу, выполнить поиск — должны появиться предложения.
4. Открыть `/reviews.html` — должен показаться блок «недоступно», без ошибок в консоли.

## Особенности serverless по сравнению с обычным сервером

- Кэш поиска и счётчики rate-limit живут в памяти одного «тёплого» инстанса функции — при холодном старте или нескольких параллельных инстансах они не общие. Функционально не критично, просто слабее ограничения.
- Никакого «сна» по 15 минут, как на Render free tier, тут нет — Vercel просто масштабирует функции до нуля и обратно, без ручного keep-alive.

## Следующий шаг: подключить базу и вернуть отзывы/алерты

1. Завести бесплатную базу на [turso.tech](https://turso.tech), получить `TURSO_DATABASE_URL` и `TURSO_AUTH_TOKEN`.
2. Добавить их в Vercel Environment Variables.
3. Заменить заглушки в `api/reviews/`, `api/admin/`, `api/alerts/create.js` на реальное хранилище через `@libsql/client` (SQL-схема почти без изменений берётся из `db/001-reviews.sql`).
4. Для алертов и поддержки — перевести `support-bot.js` на webhook (`api/telegram.js`) и добавить `crons` в `vercel.json` для периодической проверки цен вместо `setInterval`.
