КАК ЗАПУСТИТЬ
1. Если у вас уже есть рабочий файл .env — просто скопируйте его в эту папку.
2. Если .env нет: скопируйте .env.example, переименуйте копию в .env и вставьте SERPER_API_KEY.
3. Дважды нажмите START.bat
   или откройте терминал в папке и выполните:
   node server.js
4. Откройте:
   http://localhost:3000

ВАЖНО
- Не публикуйте файл .env и API-ключи в GitHub.
- .gitignore уже исключает .env.
- Для работы Node.js нужен версии 22.13 или новее (для `node:sqlite`).
- На Render добавьте секреты только в Environment: SERPER_API_KEY, а при использовании eBay — EBAY_CLIENT_ID и EBAY_CLIENT_SECRET.
- Не добавляйте реальные ключи в .env.example, HTML или JavaScript браузера.

ОТЗЫВЫ И МОДЕРАЦИЯ
- В новом локальном запуске список отзывов пустой — это нормально. Фейковые отзывы не добавляются.
- Отправка нового отзыва работает только после настройки `REVIEWS_ADMIN_PASSWORD` (32–128 символов). Новый отзыв получает статус «На проверке».
- Для Render нужен Persistent Disk и переменные `REVIEWS_DATA_DIR` (абсолютный путь), `REVIEWS_PERSISTENT_STORAGE=true`, `REVIEWS_SECRET` (не менее 32 символов) и `PUBLIC_SITE_URL=https://...`.
- Откройте `/admin-reviews.html`, войдите паролем администратора и публикуйте только проверенные отзывы. Пароль не передаётся во frontend и не хранится в localStorage.
- Если постоянный диск или пароль не настроены, отзывы доступны только для просмотра, а поиск продолжает работать.
- Полная инструкция для Render находится в `DEPLOYMENT_RU.md`.
